# Dockerized Java Application

## Overview
This project demonstrates how to containerize a Java application using Docker.

The project uses a multi-stage Docker build and a Distroless runtime image to reduce image size and improve security.

## Technologies Used
- Java
- Docker
- Distroless Image
- Linux
- Git
- GitHub
